# 商析 AI——电商经营复盘助手｜第一阶段需求

**项目定位**：个人求职作品，展示业务口径、数据建模、应用开发和测试能力；全部使用模拟数据，不宣称真实客户、收入或商用效果。

**目标用户与问题**：用 Excel 做周复盘的小电商团队，需要统一销售、退款、成本的时间与金额口径，比较前后期表现，定位商品变化和数据缺口。

**完整产品设想**：订单/退款/成本导入 → 校验 → 程序计算 → 经营看板 → AI 解释 → 人工审核 → 导出周报。本次仅实施中间的模拟数据校验、计算和看板，不实现上传、AI、审核或导出。

**第一阶段交付**：

1. 固定种子生成 90 天、20 个商品、2000 条订单明细，包含退款和成本；设置促销、成本上涨、跨期退款、成本缺失场景。
2. SQLite 建模，Flask 计算销售额、成功退款、商品成本、商品贡献利润与等长前期比较；金额精确到整数分。
3. React + TypeScript 中文看板：四张指标卡、每日趋势、商品排名、本周与上周比较、日期/商品筛选、口径和模拟数据提示。
4. 自动化测试及 Windows 本地启动说明；错误参数、空数据、缺失成本与服务失败要有明确反馈。

**核心规则**：销售按支付日，退款按成功日；退款不冲回采购成本；成本未知不能当零；贡献利润不等于净利润；前期为零不显示无穷大；观察期外不能当零。详见《需求与指标口径》与《数据库与数据字典》。

**范围与验收**：单店铺、人民币、明确日期；浏览器数值须来自后端且可通过筛选和测试复核。只监听本机；不付费、不部署、不接真实账号。不做多币种、广告归因、库存、预测或自动经营动作。后续模型只调用经参数校验的预定义只读工具，程序负责计算，禁止执行模型任意代码。

**完成条件**：文档、模拟生成器、数据库、可运行看板、核心测试和启动说明齐备。第一阶段完成后停止扩展，等待人工验收。
